# gaugeslug

Gauge and reshape slug text streams with deterministic transforms.

**Site:** https://theworker02.github.io/gaugeslug/

## Install / run

```bash
git clone https://github.com/theworker02/gaugeslug.git
cd gaugeslug
node src/cli.js
node --test
```
